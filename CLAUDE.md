# auka-backend

Бэкенд мессенджера Auka. Клиент — репо `auka-ios` рядом. Контракт и криптография — `docs/protocol.md`, любые изменения там должны совпадать с клиентами; `tools/e2e.py --vectors` генерит векторы для их тестов.

## Правила

- Репо станет **публичным**: никаких секретов, IP и личных адресов в коде и доках. Всё через env, локальный `.env` в gitignore.
- Лимит всего контейнера — **300 МБ**, в простое 66–80 МБ. Новые зависимости добавлять только если без них никак.
- Доступ deny by default: новый публичный маршрут надо явно внести в `Api.PUBLIC`.
- Сообщения сервер видеть не должен: в логах, пушах и событиях сокета нет ни текста, ни токенов.

## Проверка

JDK на Windows-машине нет, запуск через Docker:

```sh
MSYS_NO_PATHCONV=1 docker run --rm -v "$(pwd -W):/w" -v msgr-gradle:/root/.gradle -w /w eclipse-temurin:25-jdk ./gradlew --no-daemon -q test
```

После изменений в API или шифровании ещё и `tools/e2e.py` против `docker compose up`.

## Деплой

`.env` с рабочими почтовыми данными лежит локально; при деплое заполнить `PUBLIC_HOST` и `APNS_KEY_*`. Сервер ещё не выбран.
